# assets: original files

Upload originals here. The website never uses these files directly: Claude Code makes
compressed copies in `public/` when a page needs them. Use lowercase names with dashes.

| Folder | What goes in it |
| --- | --- |
| `brand/logo/` | Logo files |
| `brand/certifications/` | SVLK, FSC, JAS logos |
| `brand/line-art/` | Line drawings (tree rings, building perspective, construction diagrams) |
| `brand/textures/` | Wood texture photos |
| `brand/catalogue-photos/` | Original photos used in the catalogue, named by page |
| `clips/` | Video clips you edited for a page (e.g. `welcome-background.mov`) |
| `reels/` | The three edited process reels |
| `factory/` | Factory photos: hall, timber stock, kilns, people at work, machines, packing |
| `renders/` | Visualisations (e.g. the Semarang renders) |
| `flooring-samples/` | Reshot flooring sample photos |
| `products/` | Product photos: skirting, ceilings, doors, staircases |
| `projects/residential-semarang-yh-2026/` | Semarang project photos |
| `projects/furniture/` | Furniture photos |
| `catalogue/` | The final catalogue PDF |

To upload: open the folder on GitHub, then **Add file → Upload files**. Files over 25 MB
are refused, so trim long videos first. If a file lands in the wrong place, it gets moved here.
