# pilihkayu.id

The PilihKayu website. Built with Next.js on Vercel; see `docs/spec.md` for the full spec
and `CLAUDE.md` for the rules every session follows.

- Edit content in `/content` (see `content/README.md`).
- Each phase is built on its own branch; Vercel gives every branch a preview link.
- Merging into `main` publishes to pilihkayu.id.

Run locally: `npm install`, then `npm run dev` and open http://localhost:3000.
