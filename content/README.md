# Content files

Edit these to change the site. Components never hard-code these values.

- `settings.json`: WhatsApp number (digits only, country code first, no `+`), email,
  Instagram, catalogue file, and "coming soon" flags.
- `products.json`: product specs, start-from prices, species, production times (Phase 4).
- `projects.json`: project grid entries, tags and photos (Phase 5).
- `welcome-links.json`: the buttons on /welcome (Phase 2).

Only facts listed in `docs/spec.md` (Copy & content rules) may go in these files.
