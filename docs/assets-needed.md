# Assets needed for the whole website

A checklist to collect everything the site needs. Tick items as you add them.
Upload files to the matching `assets/` folder on GitHub (Add file → Upload files), as you did for `docs/references/`.

## How to send files

- **Originals, not WhatsApp copies.** WhatsApp shrinks photos and videos. Send from the phone's gallery, Google Photos "download original", or the camera's SD card.
- **Photos:** JPG or HEIC straight from the camera, no filters or portrait mode. Long side at least 2,400 px (any modern phone is fine). I crop, colour-correct and convert them.
- **Videos:** MP4, 1080p or better, 5–15 seconds per clip, no text or music. GitHub accepts files up to 25 MB, so trim long clips first.
- **Line art:** SVG, PDF or AI from whoever designed the catalogue. A PNG screenshot is not enough for line drawings.
- **Never stock photos.** Every image must be PilihKayu's own, or a render labelled "Visualisation".
- **People:** only with their consent. Clients by initials only, never addresses.

Priority: **P1** = needed for launch · **P2** = makes it much better · **P3** = later.
